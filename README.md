## 快速开始

### 1. 安装并检查通知

点击上方「下载 v4.3.17 APK」获取 `binance-copy-terminal-v4.3.17.apk`。APK 的 SHA-256 为 `ed8b769b15931fad358930a11edc2e3a24595767faf2da95bb255697405fddf4`。

从旧版更新时，请使用同一签名的发布包覆盖安装，以保留本机档案和设置。打开应用，在「设置 → 后台与通知 → 测试通知与提示音」允许通知并试听。长时间运行前按[网络与后台](#网络与后台)设置手机。

### 2. 获取带单组合 ID，设置合约白名单

1. 打开[币安合约跟单](https://www.binance.com/zh-CN/copy-trading)，进入带单员的**具体合约组合详情页**。在币安 App 里可从详情页分享并复制链接，再用浏览器打开。
2. 复制网址中 `/lead-details/` 后面的数字。例如，网址以 `/lead-details/4532994172262753536?timeRange=7D` 结尾时，组合 ID 是 `4532994172262753536`。
3. 在「设置 → 跟单规则」的组合 ID 输入框中**只填写这串数字**。粘贴完整链接会提示无效。通过「添加合约」勾选要跟单的品种。打开每个合约的「设置」，填写保证金、杠杆和最大不利价差，再点「保存规则」。保存新组合时会核对官网详情。以前跟过的组合可从「历史带单员」选择。

### 3. 准备 API 密钥

在应用的「设置 → 币安 U 本位合约账户」分别保存不同环境的密钥。使用系统生成的 **HMAC API Key 和 Secret Key**。

| 环境 | 去哪里创建 | 在应用里怎么保存 |
| --- | --- | --- |
| **虚拟盘（测试网）** | 登录[币安合约模拟交易](https://demo.binance.com/en/futures)，从右上角账户入口打开「API 管理 → 创建 API」。如有交易权限选项，启用合约交易。 | 「保存测试网密钥」，然后「查询测试网钱包余额」。 |
| **实盘** | 先开通 U 本位合约账户，再到币安官网「头像 → 账户 → API 管理 → 创建 API」，选择「系统生成」。创建后在 API 权限中勾选**启用读取、启用合约**，保存配置。 | 「保存实盘交易密钥」，然后查询实盘钱包余额和持仓。仅用于查询时，可单独配置「保存实盘只读密钥」。 |

**IP 访问设置。** 不熟悉 IP 白名单配置时，可选择「不限 IP」。**币安权限页允许勾选并保存「启用合约」时，不限 IP 的 HMAC 密钥也可以用于实盘交易。** 如果权限页仅允许读取，可将该密钥用于账户查询，并按币安页面提示处理合约交易权限。选择绑定 IP 时，填写手机访问合约 API 使用的公网出口 IPv4，切换 Wi-Fi、移动数据或代理出口后重新核对。提现和划转权限保持关闭。

**本机加密保存。** 点击保存后，应用将 API Key 和 Secret Key 一起用 AES-256-GCM 加密，密文保存在手机上，加密密钥由 Android Keystore 管理。实盘、只读和测试网的凭证分别保存。发起币安 API 请求时，Secret Key 留在手机上生成签名，请求把 API Key 和签名发送给币安。请妥善保管密钥，分享截图或日志前遮盖凭证。

[币安实盘 API 创建和权限说明](https://www.binance.com/zh-CN/support/faq/detail/360002502072) · [币安合约模拟盘 API 说明](https://www.binance.com/en/support/faq/detail/ab78f9a1b8824cf0a106b4229c76496d)

### 4. 从监测、演练到实盘

1. **先看信号。** 在「运行」点「开始自动抓取」，确认「上次有效抓取」持续更新。这一步只监测和归档官网信号。
2. **测试下单。** 停止监测后，点「测试网自动开平仓演练」，检查开仓、成交核对、平仓和通知。随后可用「用官网成交跟单到测试网」观察真实公开信号如何触发模拟委托。模拟盘的可交易品种、盘口和成交情况可能与实盘不同。
3. **启动实盘。** 停止测试模式，核对实盘账户的持仓、在途委托、合约白名单、杠杆和最大不利价差。**建议实盘账户空仓时再启动跟单**，以免后续信号影响已有仓位。点「启动实盘自动跟单」，选择跟单方式。选择复制仓位比例时，先定好复制系数，再在「当前为实盘跟单」提示中确认。
4. **决定是否补跟。** 首次建档后，运行页会根据公开记录列出可补跟的仓位。按合约和多空方向勾选「选择要补跟的仓位」，或选择「仅跟后续成交」。历史成交用于建档和估算仓位，补跟由你单独选择。

## 跟单怎么执行

| 模式 | 开仓和加仓的计算 | 普通部分减仓 |
| --- | --- | --- |
| **按点位跟随** | 按合约设置使用定额保证金，或按当前 U 本位 USDT **钱包余额**定比计算，再结合杠杆和合约规格换算下单量。 | 按「带单员本次减仓量 ÷ 减仓前推算仓位」算比例，再乘你同方向的实际持仓。 |
| **复制仓位比例** | 目标名义金额 = 带单成交额 ÷ 带单保证金余额 × 你的 USDT **保证金余额** × 复制系数。使用官网「带单保证金余额」一栏，系数默认 1×。 | 一般也按带单减仓成交额换算本机应减金额，上限为对应方向实际持仓。 |

- **点位减仓举例。** 带单员从可见的 0.6 BTC 减掉 0.3 BTC，你已纳入跟单的同方向实仓有 0.02 BTC，本次目标减掉 50%，也就是 0.01 BTC。
- **复制金额举例。** 带单成交额为 2,000 USDT、带单保证金余额为 1,000 USDT，你的保证金余额为 500 USDT，复制系数为 0.5×，目标名义金额就是 500 USDT。实际杠杆为 5 倍时，初始保证金约为 100 USDT，另需考虑手续费及可用余额。

- **开仓和加仓通常用 IOC 限价单**控制不利价差。参考价是 100 USDT、最大不利价差是 0.3% 时，开多最多买到 100.30，开空最低卖到 99.70，委托价还会按合约价格步长修正。超出限制会继续等价。部分成交后只处理剩余量，带单员同方向全平时会取消对应的开仓等待。
- **减仓和平仓通常用市价单**，以减少等限价期间的利润回吐或亏损扩大。实际成交价由盘口决定，仍可能滑点或部分成交。带单员可见的同方向仓位全平时，软件会尝试清掉你该方向已纳入跟单的实仓。
- **启动前已有同向仓位**时，首次勾选也会跳过该方向的补仓。之后收到带单员同一合约、同一方向的新开仓或加仓信号时，你该方向的**全部实仓会立即纳入跟单**。即使新单仍在等价，带单员随后的减仓或平仓也可能动到原有仓位。
- **小额减仓**按市价单步长向下取整。低于市价单最小数量时，点位模式跳过本次，差额不累计。复制模式在还有可跟仓位时等下一笔同方向成交再重算。复制模式若算出的应减量已覆盖实际仓位，会以全平为目标。全仓小到仍达不到最小下单量时，应在币安确认余仓。
- **跟单中尽量保持复制系数稳定。** 中途更改可能立即触发市价减仓并产生滑点。需要加仓时会等待合适的盘口，价差超限时可能迟迟无法成交。缺少换算所需的成交额或余额时，相关操作会等待数据补齐。

## 延迟与刷新

**经验上，跟单综合延迟约 2 分钟，主要时间耗在币安官网发布公开成交记录。** 本机读到记录后还需核对仓位和委托。行情超出价差限制、网络抖动、官网繁忙或补页核对，都可能拉长实际跟单时间。

**场外跟单优先选择做波段、开平仓频率适中的带单员。** 超短线交易可能在信号到达手机前就已平仓或反向。频繁跟随开平仓也会累积滑点和手续费，侵蚀跟单结果。

| 数据 | 刷新方式 |
| --- | --- |
| **带单员公开成交** | 官网轮询目标约 3 秒。上一轮未完会跳过该时点。在「运行 → 检测到的新增操作」可对照「成交」和「检测」时间。 |
| **我的持仓、钱包余额和浮动盈亏** | 通过账户 API 独立查询，正常连接下基本实时，刷新目标约 1 秒，受网络及限流影响。 |
| **我的委托和成交** | 下单后立即按原委托号核对，结果不明时继续核对原单，确认实际成交后再发成交提示。 |
| **带单保证金划转** | 约每分钟检查一次官网余额历史。发现新划转后发送通知并播放提示音。 |

带单员仓位、均价和强平价根据官网可见记录与本机档案推算，供查看参考。公开记录缺页或衔接不上时，软件会先补页核对，无法确认连续性时暂停自动委托。「成交记录」里可查看各类记录，并导出带单员成交 CSV。

### 带单保证金划转

**收到划入或划出提醒后，先核对自己的保证金和强平价。** 如果带单员划入的资金计入该仓位可用的保证金，即使持仓数量相同，实际杠杆也可能下降，强平价可能离标记价格更远。你的账户可能在同一波行情中更早触发强平。划出也可能使带单员更接近强平。划转方向和金额可在「成交记录 → 带单保证金余额历史」查看。你的风险以「运行 → 我的当前持仓」显示的币安账户数据为准，逐仓尤其要核对对应仓位实际分配的保证金。[币安 U 本位合约强平价说明](https://www.binance.com/zh-CN/support/faq/detail/b3c689c1f50a44cabb3a84e663b81d93)

**划转本身只触发提醒。** 自动加减仓由带单成交信号或你主动修改复制系数触发。自己的划转和逐仓保证金调整由你在币安操作。复制仓位比例模式按该笔信号关联的官网带单保证金余额换算新开仓、加仓和普通部分减仓的委托金额。对于相同的带单成交额，在其他条件相同时，更高的带单保证金余额会换算出更小的委托金额。

## 网络与后台

- 手机须能稳定连通币安官网 `www.binance.com` 以及对应的合约 API。实盘访问 `fapi.binance.com`，模拟盘访问 `demo-fapi.binance.com`。这两个环境的地址可见[币安 U 本位合约 API 文档](https://developers.binance.com/zh-CN/docs/products/derivatives-trading-usds-futures/general-info)。
- 在系统中给**合约跟单台和正在使用的代理应用**放开电池优化、后台运行及后台联网限制，允许自启动。系统支持时，在最近任务列表给两者加锁，保持跟单台常驻通知。使用代理时也要确认手机能稳定访问官网和所选 API。
- 锁屏后用「上次有效抓取」和常驻通知确认仍在运行。系统强制停止应用后，回应用手动启动。后台持续性受设备系统和网络影响。[Android 后台运行说明](https://developer.android.com/topic/performance/background-optimization)

## 暂停与排障

| 情况 | 查看或操作 |
| --- | --- |
| 官网页面报错、抓取不更新 | 查看「上次取数失败」。显示访问提示时，可用「打开币安组合页」核对官网状态，再点「重试官网读取」。遇到地区限制、登录或安全验证要求，遵循币安页面提示。 |
| 没有开仓或一直等待 | 检查「等待开仓与调仓」和「自动运行记录」。重点核对合约白名单、方向、价差、最小下单量、资金、API 合约权限和 IP。对单笔可点「取消这笔等待」。 |
| API 权限只有读取或启用合约失败 | 核对币安权限页和 U 本位合约账户状态。使用了 IP 白名单时，检查当前公网出口。若密钥早于合约账户开通，开通后重新创建。 |
| 想暂时控制新增风险 | 用「暂停开仓，继续处理平仓」，有效平仓信号仍会处理。 |
| 想彻底停止或切换带单员 | 点「停止自动运行」。已成交仓位留在币安账户，打开币安核对持仓和在途委托。切换组合后会建立新一轮基线，旧档案保留。 |
