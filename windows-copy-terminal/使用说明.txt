合约跟单台 4.2.18　Windows x64 测试版

完整解压后双击 CopyTerminal.exe。适用于 Windows 10 x64，需 .NET Framework 4.7.2 或更新版本和 Microsoft Edge WebView2 Evergreen Runtime。Java 已随包提供。首次打开会校验程序文件。请勿单独移动 exe。
WebView2 官方下载 https://developer.microsoft.com/microsoft-edge/webview2/

首次使用
1. 打开「跟单设置」，输入带单组合的纯数字 ID，添加要跟踪的合约并保存。币安组合网页地址中 lead-details/ 后的数字是组合 ID。官网和合约 API 都需要可从电脑网络正常访问。
2. 仅查看官网成交可直接启动「官网监测」。测试网交易和实盘交易请分别保存对应环境的 HMAC 密钥并启用相应合约交易权限。实盘还可单独配置只读密钥。凭证使用 AES-GCM 加密，本机主密钥由 Windows 当前用户的 DPAPI 保护。请使用自己的 Windows 用户账户。
3. 在「运行总览」启动，选择按点位或复制仓位。首次发现已有仓位时逐项选择。建议先用测试网，实盘开始前核对仓位。复制系数 0.5 表示复制带单员相对资金敞口的一半，2 表示两倍。中途降低系数可能立即市价减仓，提高系数可能因价差一直等待。
4. 开仓按允许的不利价差执行，超限进入等待。减仓一般走市价。带单员的持仓、均价及强平价来自可见成交推算。官网发布延迟、网络中断、流动性和交易所规则会影响跟单。原项目的使用观察为综合延迟约两分钟，具体以检测时间为准。
5. 运行页可暂停开仓、取消单笔等待或停止运行。停止运行不会平掉交易所已有仓位。「成交记录」可翻页和导出当前组合的带单员成交 CSV。「保证金划转」仅记录官方划转，注意带单员补保证金可能使双方强平风险出现差异。
6. 关闭主窗口会收至系统托盘。双击托盘图标重新打开，右键选择「停止并退出」才能结束程序。休眠、手动睡眠、断网和关机会中断运行；恢复后请检查官网状态、账户仓位和待核对委托。请勿让手机和电脑同时跟同一实盘账户。
7. 本地数据目录为 %LOCALAPPDATA%\CopyTerminal。升级时解压至新的程序目录并保留数据目录。Windows 用户凭证不可通过复制目录移至另一账户。Windows 首次启动是独立跟单会话，不会自动导入手机档案。

4.2.18 更新
- 建档和读档采用 Android 4.3.20 的分页、旧档案续接及同秒核对逻辑。
- 完全相同的开仓只记一笔。疑似重复平仓直接展开成交列表，按同合约同方向的开平仓余量核对。
- 分页多轮无进展时保留已经读到的记录，可查看官网列表后重新读取。

4.2.15 更新
- 切回旧档案时，已确认的重合成交和本次未出现的待复核项不再触发重读；本轮新增中仍可能改变成交笔数的同秒记录继续复核。
- 开启新的跟单会话时，续接完档案后按现有可补仓位给出选择。

4.2.14 更新
- 切回已建档带单员或中断后恢复时，核对最新可见成交并在接上旧档案后停止翻页。

4.2.13 更新
- 首次补已有仓位与调整复制系数都使用调仓点差；两种跟单模式均可在启动时填写。
- 增仓按成交后的持仓均价检查。已有均价超限时，仅在整笔成交能使均价回到范围的情况下提交限价整笔成交委托。

4.2.12 更新
- 增仓报价优于带单仓位均价时，可按目标继续补仓。其余报价按成交后持仓均价和不利价差上限核对。

4.2.11 更新
- 初次补仓和合并跟单按带单员最新已核对的仓位均价检查。增仓前复核本次成交后的本账户均价。
- 只跟随后续成交时，保留该模式的跟单数量范围。等待栏显示带单均价和实际卡住的条件。

4.2.10 更新
- 普通跟单成交显示开、加、减、平仓。初次补仓和调整复制系数标记为复制调仓。
- 等待栏增加具体原因，修复部分委托因可用保证金核对和杠杆上限重算而持续等待的问题。
- 成交记录三张表格随窗口高度调整。

4.2.9 更新
- 首次建档按官网可展开的成交读取，最多保留最新成交往前 7 天。繁忙时延长重试间隔。
- 合约白名单支持币安实盘列表中的股票和其他 TradFi USDT 永续。
- 限制主页滚动范围，各栏分页按钮固定在本栏底部。

4.2.8 更新
日期续读时直接修改需要调整的日期。开始日期保持原样时，只操作结束日期控件。
核对官网日期和刷新后的成交列表后再合并。日期跳回原值时会重新选择一次。

4.2.7 更新
新跟单建档若遇到「更多」多次未返回下一页，会保留已读记录，缩短日期范围续读较早成交。
校验交界处的成交顺序和数量，读到末尾后再建档。运行状态会显示未推进的页码或日期续读错误。

4.2.6 更新
读取到同秒同值的成交时，用币安仓位历史的开平仓时间、最大持仓量和已平仓量核对。
只有数量和仓位过程能唯一对齐，才归并多余副本。更新后会核对已入档的历史基线。

4.2.5 更新
重连核对完成后，按已保存的复制系数重新计算调仓目标。
调仓加仓使用复制系数窗口设置的最大不利价差。

4.2.4 更新
「检测到的新增操作」从本地成交档案分页，已读到的缺口记录标记「待核对」。核对完成后保留第一次检测的时间。
复制调仓会并行检查不同合约。就绪的合约可以先处理，并按每笔委托重新核对仓位和可用保证金。
成交等通知在所用显示器右上角出现。最多同时显示三条，其余按到达顺序排队。通知显示约 7.5–13.5 秒，鼠标悬停可延长阅读时间，右上角 × 可关闭。可在「设置 → 后台与通知」测试。
